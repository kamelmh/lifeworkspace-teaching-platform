# Ta'allim Pilot — Parallel-Form Test Specifications

> **Purpose:** Grammar + Vocabulary tests for the 6-week middle-school pilot
> **Target:** 120 students (Experimental vs Control), 4 teachers, 6 weeks
> **Paper scope:** Grammar = primary (H1–H3); Vocabulary = secondary/exploratory (H4)
> **Last Updated:** 2026-07-27
> **v2 Status:** All 7 test files rewritten — B1 coverage added, P0 bugs fixed, answer keys rebalanced

---

## 1 · Test Design Overview

| Test | Target | Items | Forms | Duration | Pass Mark | KR-20 Target |
|------|--------|-------|-------|----------|-----------|--------------|
| **Grammar Test** | 60 structures | 60 | 3 (A/B/C) | 60 min | 50% (30/60) | ≥ .70 |
| **Vocabulary Test** | 60 items | 60 | 3 (A/B/C) | 45 min | 50% (30/60) | ≥ .70 |

### Form Usage

| Timepoint | Grammar Form | Vocabulary Form |
|-----------|-------------|-----------------|
| Pretest (Wk 1) | Form A | Form A |
| Posttest (Wk 6) | Form B | Form B |
| Delayed (Wk 8) | Form C | Form C |

### Why Parallel Forms

- Same difficulty level across forms (counterbalanced)
- No practice/memory effect between pre/post/delayed
- Each form tests the same 60 structures/items, just different contexts

### 2B · Item Type Specifications

#### Type A: MCQ (20 items per form)

**Format:**
```
She _____ a student.
A) am    B) is    C) are    D) be
```

**Rules:**
- 4 options (A/B/C/D), one correct
- Distractors based on common L1-transfer errors (Arabic/French)
- No "all of the above" or "none of the above"
- Each item tests ONE structure
- Stems should be short (1 line if possible)

**Example distractors by structure:**
| Structure | Correct | Distractor 1 (L1) | Distractor 2 | Distractor 3 |
|-----------|---------|-------------------|--------------|--------------|
| be (am/is/are) | is | am (number error) | are (number error) | be (base form) |
| past simple (irregular) | went | goed (overgeneralization) | going (wrong tense) | go (base form) |
| have/has | has | have (number error) | having (progressive) | haves (overgeneralization) |

#### Type B: Fill-blank (15 items per form)

**Format:**
```
I _____ to school every day. (go)
```

**Rules:**
- One blank per item
- Base form given in parentheses
- Student writes correct form
- Acceptable answers listed in answer key (spelling variants OK)
- No multiple blanks per item

#### Type C: Error Correction (10 items per form)

**Format:**
```
She don't like coffee.
________
```

**Rules:**
- One error per sentence (never two)
- Student underlines error AND writes correction
- Error types: wrong verb form, wrong agreement, wrong preposition, wrong tense
- Acceptable: "doesn't" or "does not" for the correction

#### Type D: Sentence Building (10 items per form)

**Format:**
```
school / goes / every / he / day / to
```

**Rules:**
- Words separated by slashes
- First word NOT capitalized (trick: student must capitalize)
- Punctuation NOT included (student adds period)
- All words must be used exactly once

---

### 2C · Counterbalancing Strategy

For each structure, create 3 parallel items (one per form) that test the same grammar point with different lexical content.

**Example:**

| Form A | Form B | Form C |
|--------|--------|--------|
| She **is** a student. | He **is** a doctor. | They **are** friends. |
| I **went** to the market. | She **went** to school. | We **went** to the park. |
| He **doesn't** like tea. | She **doesn't** like coffee. | They **doesn't** like milk. |

**Quality check:** Before piloting, have 2 teachers review all 3 forms for:
- Equivalent difficulty
- No ambiguity in any item
- No cultural bias
- Consistent instruction wording

## 3 · Vocabulary Test — Item Selection

### Source: 640 middle-school vocabulary items (1AM–4AM)

60 items selected from across 4 years, weighted by:
- High frequency in Algerian textbooks
- Concrete/visualizable nouns (easier to test)
- Abstract nouns + verbs for B1 level
- No cognates (too easy — "hospital", "telephone" excluded)
- **60 distinct words** (no duplicates across levels)

### 3B · Item Type Specifications

#### Type A: Picture-Word Matching (10 items)

**Format:**
```
Match the word to its picture:

1. school     [IMAGE: school building]
2. water      [IMAGE: glass of water]
3. teacher    [IMAGE: person at blackboard]
...
```

**Rules:**
- Use simple, culturally appropriate clip-art (no Western-specific imagery)
- Each picture has ONE correct word
- 10 words from 1AM-2AM (concrete nouns)
- 4-5 pictures per page, numbered clearly

#### Type B: MCQ — Definition/Synonym (15 items)

**Format:**
```
What does "holiday" mean?
A) سفر     B) عطلة     C) فندق     D) مدينة
```

**Rules:**
- Arabic definitions for A1-A2 items
- English synonyms for B1 items
- 4 options, one correct
- Distractors from same category (all places, all people, etc.)

#### Type C: Fill-blank — Context (15 items)

**Format:**
```
My mother is a ____. She works at the hospital. (doctor)
```

**Rules:**
- Clue in second sentence
- Base word given in parentheses
- Student writes correct form
- Tests word meaning + spelling

#### Type D: Translation AR→EN (10 items)

**Format:**
```
translate: مدرسة → ____________
```

**Rules:**
- Single Arabic word or short phrase
- Student writes English equivalent
- Tests productive vocabulary
- Acceptable spelling variants listed

#### Type E: Sentence Use (10 items)

**Format:**
```
Use "environment" in a sentence:
_______________________________
```

**Rules:**
- Student writes original sentence using the word
- Scored: 1 mark for correct meaning + 1 mark for grammatical accuracy (partial credit)
- Tests depth of word knowledge

## 4 · Counterbalancing Strategy

For each vocabulary item, create 3 parallel versions:

| Form A | Form B | Form C |
|--------|--------|--------|
| school (image of school) | school (image of classroom) | school (image of students) |
| holiday = عطلة | holiday = إجازة | holiday = راحة |
| My mother is a ___. (doctor) | My father is a ___. (doctor) | My sister is a ___. (doctor) |
| مدرسة → school | مدرسة → school | مدرسة → school |
| "environment" in a sentence | "pollution" in a sentence | "ecology" in a sentence |

**Rule:** Same word, different context. Difficulty stays constant across forms.

## 5 · Validation Protocol

### Before Piloting

| Step | Who | Action |
|------|-----|--------|
| 1 | Kamel | Draft all 3 forms for grammar + 3 forms for vocabulary |
| 2 | 2 teachers | Review for difficulty equivalence, ambiguity, cultural bias |
| 3 | 30 non-participants | Pilot-test all forms; compute item difficulty + discrimination |
| 4 | Kamel | Drop/revise items with difficulty < .30 or > .95, or discrimination < .20 |
| 5 | Kamel | Compute KR-20 for each form; drop items that lower reliability |
| 6 | Final | Lock forms A/B/C; photocopy for pilot |

### Item Analysis Metrics

| Metric | Formula | Acceptable Range |
|--------|---------|-----------------|
| **Difficulty (p)** | # correct / # total | .30 – .95 |
| **Discrimination (D)** | (upper 27% correct − lower 27% correct) / 27% of N | ≥ .20 |
| **Reliability (KR-20)** | k/(k-1) × (1 − Σpq/σ²) | ≥ .70 |

### During Piloting

| Check | Frequency | Action |
|-------|-----------|--------|
| Form equivalence | After pretest | Independent-samples t on pretest scores (A vs A, no difference expected) |
| Test-retest reliability | After delayed | Correlation between posttest and delayed (expected r ≥ .60) |
| Floor/ceiling effects | After each timepoint | Check if scores cluster near 0 or 60 |

## 6 · Scoring Rules

### Grammar Test

| Section | Scoring |
|---------|---------|
| MCQ | 1 mark per correct answer (no penalty for guessing) |
| Fill-blank | 1 mark per correct form (spelling must be correct) |
| Error correction | 1 mark: underline error (0.5) + write correction (0.5) |
| Sentence building | 1 mark: correct word order + capitalization + punctuation |

### Vocabulary Test

| Section | Scoring |
|---------|---------|
| Picture matching | 1 mark per correct match |
| MCQ | 1 mark per correct answer |
| Fill-blank | 1 mark per correct word |
| Translation | 1 mark per correct translation |
| Sentence use | 1 mark for correct meaning + 1 mark for grammar (partial credit, max 1) |

### Total Scores

- Grammar: 55 points → convert to percentage (× 100/55)
- Vocabulary: 60 points → percentage directly
- Both reported as **0–100 scale** for ANCOVA
